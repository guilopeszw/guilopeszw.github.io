title: on sub-5ms latency and why it changes the instrument

a chord-recognition api that answers in under five milliseconds is not a faster version of a slow one. it crosses a threshold: below the ear's fusion window, the machine stops being a tool you consult and becomes part of the instrument you play.

> latency is the difference between an assistant and a collaborator.

you buy that speed with a smaller model and a tighter feature window. inline `code`, lists, quotes, and images all render from plain markdown you write in the browser.

## the tradeoff nobody mentions

- smaller models forget more context
- tighter windows miss slow harmonic movement
- but the feel — the feel is worth it
